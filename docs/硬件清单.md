## 2. 主控板：leap_ros_pro 控制板（ESP32-S3）

| 项 | 实测值 |
|---|---|
| 产品名 | **leap_ros_pro 控制板**（¥198） |
| 设备名（固件内） | `Maturo_80456B5771C0` |
| 芯片 | ESP32-S3（xtensa，ESP-IDF 5.2.x） |
| Flash | 4 MiB（分区已用 3100 KiB） |
| RAM | 268 KiB（空闲约 89 KiB） |
| 片内温度 | 43~45 °C |
| WiFi | STA 模式，`Xiaomi` 网络，−50~−60 dBm |
| 通信 | micro-ROS over UDP，指向 `192.168.31.104:8888` |
| 底盘类型 | `mecanum`（四轮麦轮） |
| 配网方式 | 板载 HTTP 服务，`http://192.168.31.117/` |

**固件功能**：

- 麦轮逆/正运动学（`mecanum_kinematics.cpp`）
- 每轮速度环 PID（`kp/ki/kd` 存 NVS，可通过 ROS 服务在线改）
- 里程计积分（用 IMU yaw 作为航向）
- IMU：`LSM6DS3`，I2C，互补滤波输出 `yaw/pitch/roll`
- 电池监测：ADC 分压，实测 `adc*7.17 ≈ 电池电压`
- 超声波、WS2812 灯效、按键、蜂鸣器

**提供的 HTTP API**（板载配网页）：

| 接口 | 说明 |
|---|---|
| `GET /api/status` | 状态：motion / battery / wifi / memory / imu |
| `GET /api/runtime-config` | 读运行时配置 |
| `POST /api/runtime-config` | **改配置并重启 micro-ROS 传输层**（表单格式，非 JSON） |

> `comm_mode=micro_ros&chassis_type=mecanum&microros_agent_ip=...&microros_agent_port=8888`
> 返回 `{"ok":true,"restart":true}` —— 这就是不用断电重连 micro-ROS 的办法。

## 3. 电机与驱动

| 部件 | 型号 | 参数 |
|---|---|---|
| 电机 + 底盘 | **趣轮 MG370 1:32** ×4 + GMR 编码器 + 底板（¥180，二手） | 12 V，空载 300 rpm / 额定 260 rpm，额定扭矩 1.5 kg·cm，堵转 8.7 kg·cm，13 W |
| 编码器 | **GMR 500 ppr**（电机轴） | 500 × 4（正交）× 32（减速比）= **64000 计数/轮转** |
| 驱动 | **AT8236** ×4（集成在 leap_ros_pro 控制板上，非独立采购） | 双 H 桥，IN1/IN2 + PWM（0~1000） |
| 轮子 | 麦轮，直径 80 mm | 轮距 340 mm，轴距 295 mm |

**里程计标定记录**：

- 固件常数 `kEncoderCountsPerWheelRev = 68000`（手册理论值 64000，差 6.25%）
- 实测直线 3.25 m → 报 3.317 m，**多报 2.05%** → 上位机按 `odom_linear_scale=0.980` 修正
- 命令→实际速度效率：PID `kp=7.5, ki=0` 时约 **35%**；改为 `kp=12, ki=1` 后约 **65%**

## 4. 传感器

| 传感器 | 型号 | 接口 | 说明 |
|---|---|---|---|
| 激光雷达 | **LDROBOT STL-27L**（¥86，二手） | USB-CH340，921600 bps | 10 Hz，每圈约 2170 点（点数有抖动，需归一化到 2100） |
| IMU | **LSM6DS3** | I2C（板载） | 陀螺 + 加速度，固件内互补滤波 |
| 电池检测 | ADC 分压 | 板载 | 分压比 ≈ 7.17 |
| 摄像头 | 见 `/dev/video0` | USB | 上位机侧做 MJPEG/WebRTC 推流 |

雷达实测特性（影响建图）：

- 每圈点数在 **2135~2176** 之间抖动，且 `angle_increment` 也在变 → 必须重采样成定长
- 约 **7.8% 的读数是 NaN** → 必须替换成有限值，否则 karto 会把 NaN 当有效值而崩溃
- 安装角：`base_link → base_laser` = **(0, 0, 0.18) m，yaw = −92°**

## 5. 语音模块

| 项 | 实测值 |
|---|---|
| 产品 | **创乐博 AI 大模型语音交互模块**（¥120） |
| 芯片 | **CI1302**（AI 离线语音识别） |
| 接口 | USB-CH340，**115200 bps** |
| 设备节点 | `/dev/voice` → `ttyUSB1`（USB 口 `1-1.4.1`） |
| 唤醒词 | **「小创小创」**（也支持「你好小创」） |
| 串口协议 | 5 字节定长帧 `AA 55 <cmd> <data> FB` |

**帧定义**：

| 帧 | 含义 |
|---|---|
| `AA 55 03 00 FB` | 唤醒 |
| `AA 55 00 01 FB` | 前进 |
| `AA 55 00 02 FB` | 后退 |
| `AA 55 00 03 FB` | 左转 |
| `AA 55 00 04 FB` | 右转 |
| `AA 55 00 09 FB` | 停止 |

**播报（TTS）**：

模块自身只能播固定词条；**变量文本**（如「到达 3 号点」）走上位机：

- 主路径：`edge-tts` 在线合成（`zh-CN-XiaoxiaoNeural`）→ mp3 → `mpg123` → **USB 声卡**
- 兜底：`espeak-ng -v cmn` 离线合成 → wav → `aplay`
- 缓存：`/root/.cache/tts/`，按 `语音+文本` 的 md5 命名，重复播报秒出

## 6. 上位机：Panther（黑豹）X2（RK3566）

| 项 | 实测值 |
|---|---|
| 型号 | **Panther（黑豹）X2**（RK3566，aarch64，¥150 二手） |
| CPU / RAM | 4 核 / 3.8 GiB |
| 系统 | Armbian OS 26.08.0 noble（Ubuntu 24.04 LTS） |
| 存储 | eMMC 29 GB（已用 38%） |
| 网络 | `wlan0` = 192.168.31.104 |
| ROS 2 | **Jazzy**（`/opt/ros/jazzy`） |
| 关键包 | `slam_toolbox`、`robot_localization`、`foxglove_bridge`、`rosbag2` |
| micro-ROS agent | 装在 `/root/micro_ros_ws`（非 apt 包），systemd 服务 `microros-agent` |

**USB 设备树（实测）**：

```
Bus 001 Device 002: 35d6:2510 Bridgesil USB2.1 Hub
Bus 001 Device 003: 1a86:7523 CH340  →  /dev/lidar  (1-1.2)
Bus 001 Device 004: 1a86:8091 CH340 USB HUB
Bus 001 Device 005: 1a86:7523 CH340  →  /dev/voice  (1-1.4.1)
Bus 001 Device 006: 0c76:161f JMTek USB PnP Audio Device
```

**注意**：两个 CH340 型号完全相同，**必须靠 USB 物理端口（KERNELS）区分**，不能靠 VID:PID。

## 10. 关键话题

| 话题 | 类型 | 方向 | 说明 |
|---|---|---|---|
| `/cmd_vel_raw` | `Twist` | 网页/语音/导航 → 整形节点 | **所有速度发布者都应该发这里** |
| `/cmd_vel` | `Twist` | 整形节点 → 主控 | 已做限幅 + 符号翻转 + 最小速度补偿 |
| `/odom` | `Odometry` | 主控 → 上位机 | 轮式里程计 |
| `/imu` | `Imu` | 主控 → 上位机 | 原始 IMU（含零偏） |
| `/imu/ekf_input` | `Imu` | 适配器 → EKF | 已去零偏 |
| `/odom/ekf_input` | `Odometry` | 适配器 → EKF | 已做符号/比例标定 |
| `/scan` | `LaserScan` | 雷达 | 点数不定、含 NaN |
| `/scan_fixed` | `LaserScan` | 归一化节点 | **定长 2100 点、无 NaN** |
| `/map` | `OccupancyGrid` | SLAM / 导航 / 中继 | latched，中继以 1 Hz 重播 |
| `/tf`, `/web/tf` | `TFMessage` | — | `/web/tf` 是含静态变换的聚合版 |
| `/battery_state` | `BatteryState` | 主控 → 上位机 | — |
| `/goal_pose` | `PoseStamped` | 网页 → 导航 | 目标点 |
| `/initialpose` | `PoseWithCovarianceStamped` | 网页/自动定位 → 导航 | 初始位姿 |
